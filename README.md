# صفحة جو أجواء

صفحة هبوط عربية خفيفة لخدمات تنظيف الكنب والمجالس، جاهزة للرفع على GitHub Pages أو أي استضافة ملفات ثابتة.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. افتح **Settings → Pages**.
3. اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)`.
4. احفظ الإعدادات وانتظر ظهور رابط الموقع.

الصفحة لا تحتاج تثبيت أي مكتبات أو تشغيل أوامر بناء. افتح `index.html` مباشرة للمعاينة.
